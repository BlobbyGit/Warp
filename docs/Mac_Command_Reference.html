Security & Authentication

PAM Setup (YubiKey FIDO)

pamu2fcfg -o pam://$(hostname) -i pam://$(hostname) > ~/.config/Yubico/u2f_keys

Test PIV Authentication

sudo -k && sudo whoami

Disable Screen Sharing

sudo /System/Library/CoreServices/RemoteManagement/ARDAgent.app/Contents/Resources/kickstart -deactivate -stop

Check Remote Login Status

sudo systemsetup -getremotelogin

macOS Firewall Stealth Mode (ignore ping/probes)

/usr/libexec/ApplicationFirewall/socketfilterfw --getstealthmode

sudo /usr/libexec/ApplicationFirewall/socketfilterfw --setstealthmode on

Distinct from LuLu's own stealth setting (see LuLu Firewall Status below). Both confirmed ON as of Aug 2026.

Require Password Immediately After Sleep/Screensaver

defaults write com.apple.screensaver askForPassword -int 1

defaults write com.apple.screensaver askForPasswordDelay -int 0

Disable Unwanted System Services (e.g. stray Apache/Web Sharing, FTP proxy)

pgrep -fl httpd; lsof -nP -iTCP:80 -sTCP:LISTEN # Check if Apache is unexpectedly running

sudo apachectl stop && sudo launchctl disable system/org.apache.httpd

sudo launchctl disable system/com.apple.ftp-proxy

Apple's own LaunchDaemons are SIP-protected: `launchctl bootout`/`unload` fails with "Input/output error". Use `launchctl disable system/<label>` instead, then stop the running process.



Backup & Recovery

Bitwarden Backup

Run Encrypted Backup:

/Users/jarrodstebbing/bitwarden_backup.sh

View Backup README:

cat /Volumes/SD/BitwardenBackups/README.md

Test Backup Script:

ls -la /Users/jarrodstebbing/bitwarden_backup.sh

Restore from Backup:

gpg --decrypt /Volumes/SD/BitwardenBackups/bw_backup_YYYY-MM-DD_HH-MM.json.gpg > restored_backup.json

GPG Keys Backup

Backup All GPG Keys to SD Card:

mkdir -p "/Volumes/SD/GPG backup" && \

gpg --export --armor --output "/Volumes/SD/GPG backup/all-public-keys.asc" && \

gpg --export-secret-keys --armor --output "/Volumes/SD/GPG backup/all-private-keys.asc" && \

gpg --export-ownertrust > "/Volumes/SD/GPG backup/ownertrust.txt"

Verify Backup:

ls -lh "/Volumes/SD/GPG backup/"

Restore GPG Keys:

# Import public keys

gpg --import "/Volumes/SD/GPG backup/all-public-keys.asc"


# Import private keys

gpg --import "/Volumes/SD/GPG backup/all-private-keys.asc"


# Restore trust database

gpg --import-ownertrust "/Volumes/SD/GPG backup/ownertrust.txt"

List Backed Up Keys:

gpg --list-secret-keys

Create Bootable macOS USB

1. Download macOS installer:

softwareupdate --fetch-full-installer --full-installer-version 15.6.1

2. Create bootable USB:

sudo /Applications/Install\ macOS\ Sequoia.app/Contents/Resources/createinstallmedia --volume "/Volumes/Seqoiua reinstall"

3. Boot from USB:
Hold Option/Alt at startup, select USB, then reinstall or restore from Time Machine.

Reinstall macOS from Bootable Drive

Boot into Recovery from USB:

  1. Shut down your Mac completely
  2. Insert the bootable USB drive
  3. Press and hold Option/Alt key while pressing the power button
  4. Select the USB installer (usually shows as "Install macOS [Version]")
  5. Release the Option/Alt key when the installer loads

Choose Installation Type:

Option A: Clean Install (Erase Everything)

# From Recovery, open Disk Utility:

# 1. Erase main disk (usually "Macintosh HD")

# 2. Format as APFS

# 3. Close Disk Utility and select "Reinstall macOS"

# 4. Follow the installation wizard

Option B: Reinstall Over Existing System (Keep Files)

  • From the main recovery screen, select "Reinstall macOS"
  • This preserves user files, apps, and settings
  • Useful for fixing system issues without losing data

Option C: Restore from Time Machine

  • Connect your Time Machine backup drive
  • Select "Restore from Time Machine Backup"
  • Choose your backup and destination disk
  • Wait for restoration to complete
  • This restores EVERYTHING exactly as it was (preferred method for complete replication)

Complete System Replication Using Time Machine

RECOMMENDED METHOD: Full Time Machine Restore

This is the easiest way to replicate your exact setup after installing from bootable drive.

During macOS Installation:

  1. Boot from "Seqoiua reinstall" USB (hold Option/Alt at startup)
  2. In Disk Utility, erase your main drive (Macintosh HD) as APFS
  3. Close Disk Utility
  4. Select "Restore from Time Machine Backup"
  5. Connect your Time Machine drive ("Time Machine Backup" volume)
  6. Select your most recent backup
  7. Choose "Macintosh HD" as destination
  8. Wait for complete restoration (may take 1-3 hours depending on data size)
  9. Mac will restart with EVERYTHING restored:
    • All apps (Safari with AdGuard/uBlock, Bitwarden, etc.)
    • All system settings (locale, WiFi country, DNS)
    • All scripts (battery_monitor, system_check, bitwarden_backup)
    • All LaunchAgents
    • All preferences and configurations
    • All documents and files

After Time Machine Restore:

# Verify everything is restored

ls -la ~/*.sh                           # Check scripts

ls -la ~/Library/LaunchAgents/          # Check LaunchAgents

cat ~/.ssh/id_ed25519.pub               # Verify SSH key

brew --version                          # Check Homebrew


# If needed, reload LaunchAgents

launchctl load ~/Library/LaunchAgents/com.user.batterymonitor.plist


# Verify system settings

defaults read NSGlobalDomain AppleLocale  # Should show en_AU

systemsetup -gettimezone                  # Should show Australia/Sydney

What Gets Restored Automatically:

  • ✅ Safari with extensions (AdGuard, uBlock Origin)
  • ✅ All browser bookmarks and settings
  • ✅ Bitwarden app and configuration
  • ✅ Homebrew and all installed packages
  • ✅ All your scripts and their permissions
  • ✅ SSH keys and YubiKey configuration
  • ✅ Lulu firewall rules
  • ✅ Homebridge setup
  • ✅ ClamAV configuration
  • ✅ Network settings (DNS, WiFi)
  • ✅ All system preferences
  • ✅ Application data and caches

SMB & NetBIOS

Disable NetBIOS (Permanent)

./disable_netbios_permanent.sh

Turn Off NetBIOS (Manual)

defaults write /Library/Preferences/SystemConfiguration/com.apple.smb.server NetBIOSName -string ""

Check NetBIOS Status

defaults read /Library/Preferences/SystemConfiguration/com.apple.smb.server NetBIOSName

Empty string means it's disabled

Disable SMB Services

sudo launchctl unload -w /System/Library/LaunchDaemons/com.apple.smbd.plist

sudo defaults delete /Library/Preferences/SystemConfiguration/com.apple.smb.server.plist NetBIOSName

Verify SMB Disabled

ps aux | grep -E "smbd|netbiosd" | grep -v grep

launchctl list | grep smbd

Re-enable SMB (if needed)

sudo launchctl load -w /System/Library/LaunchDaemons/com.apple.netbiosd.plist

sudo launchctl load -w /System/Library/LaunchDaemons/com.apple.smbd.plist

NetBIOS Monitor Log

cat ~/netbios_monitor.log

Recommended order:

  1. Block Apple telemetry (low risk, high privacy)
  2. Allow essential system services (iCloud, updates, push notifications)
  3. Allow your apps (Safari, Mail, Bitwarden, security tools)
  4. Set developer tools to Prompt mode (node, python, ruby)
  5. Configure Homebridge properly
  6. Enable Block Mode (after everything works)

sudo cp ~/com.jarrodstebbing.tmretention.plist /Library/LaunchDaemons/

sudo launchctl bootstrap system /Library/LaunchDaemons/com.jarrodstebbing.tmretention.plist

Runs tm_retention.sh --keep 40 --delete every hour as root (no-ops harmlessly if the drive isn't connected). Time Machine itself backs up hourly automatically once enabled - this just keeps the 1TB drive from filling up.
